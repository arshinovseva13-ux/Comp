О проекте

Orbit Git — собственная интерфейсная Git-мастерская.

Что работает в этой версии

Создание локальных репозиториев, редактирование файлов, снимки коммитов, просмотр истории, JSON-резервные копии и поиск публичных репозиториев GitHub.

Честно о возможностях

GitHub Pages не запускает серверный Git и не может безопасно хранить GitHub-токен. Поэтому коммиты этой версии хранятся в localStorage на устройстве, а не отправляются в удалённый Git-репозиторий. Для настоящих push/pull, клонирования и совместной работы нужен серверный backend или авторизация через GitHub App/OAuth.

Сохранность

Исходный проект Comp сохранён в ветке backup/comp-original. Данные Orbit Git находятся в хранилище браузера: экспортируй резервную копию, если они важны.
