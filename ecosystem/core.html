NEXORA Core · версия 0.2

Единое ядро рабочего пространства

Одна точка для поиска по проектам, задачам и заметкам, проверки состояния хранилища и переноса своих данных между браузерами.

● ЛОКАЛЬНОЕ ЯДРО
0Проектов
0Задач завершено
0Заметок
Core готов. Данные остаются в этом браузере.

Экспорт создаёт JSON-файл для резервной копии. Импорт заменяет текущие проекты, задачи и заметки данными из выбранного файла после проверки формата. Никакие данные не отправляются на сервер.

NEXORA Forge · версия 0.1

Создавай прямо в браузере

Мини-лаборатория HTML/CSS/JavaScript: редактируй код, запускай предпросмотр в изолированном фрейме и сохраняй результат одним HTML-файлом. Без регистрации и API-ключей.

● ЛОКАЛЬНЫЙ РЕДАКТОР
Готово. Код по умолчанию — стартовый шаблон.Код хранится только в этом браузере · предпросмотр изолирован

Важно: это первая версия редактора, а не полноценная IDE. Она не устанавливает пакеты, не запускает серверный код и не публикует проекты в интернет. Не запускай незнакомый код, если не понимаешь, что он делает.

История обновлений

Прозрачная хронология развития платформы. Здесь отмечаются изменения, а не выдуманные достижения.

22.10.2026
NAVIGATION · 0.1

Карточки быстрого доступа

Добавлена адаптивная панель карточек для быстрого перехода к Desk, Forge, Core, истории, архитектуре и дорожной карте. Будущие модули отмечены статусами, чтобы не путать планы с готовыми функциями.

22.10.2026
CORE · 0.3

Единое ядро и переносимость данных

Добавлен общий поиск по рабочим данным, счётчики состояния, экспорт JSON и импорт с проверкой структуры. Эти функции работают локально в браузере; облачная синхронизация пока не реализована.

22.10.2026
FORGE · 0.1

Браузерная лаборатория кода

Добавлены HTML/CSS/JavaScript редакторы, изолированный предпросмотр, локальное сохранение, пример и экспорт самостоятельного HTML-файла. Публикация и серверное выполнение пока не реализованы.

22.10.2026
DESK · 0.1

Первое рабочее пространство

Создание и удаление проектов, список задач с отметкой выполнения и быстрые заметки с сохранением в localStorage.

Принцип устройства

Не набор продуктов — связанная архитектура.

Общее ядро должно постепенно объединять идентификацию, пользовательские настройки, проекты, разрешения и интеграции. Конфиденциальность и возможность отключать связи — часть архитектуры, а не дополнение.

Ядро

Аккаунт, настройки, единая навигация и управление разрешениями.

СЛОЙ 02

Инструменты

ИИ, разработка, обучение, творчество и личная продуктивность.

СЛОЙ 03

Связи

API, импорт и экспорт данных, интеграции и совместные сценарии.
